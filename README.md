# World In Words

신문지 색 배경의 텍스트 전용 헤드라인 사이트. 24개 국가·지역의 원어 기사 제목과 출처, 발행일만 표시합니다. 기사 본문, 원문 링크, 그림, 아이콘, 도형은 표시하지 않습니다. 국가 선택·검색·정렬·더 보기를 제공합니다.

## 실행과 자동 갱신

`python3 scripts/serve.py 8765`

http://localhost:8765 에서 열 수 있습니다. Python 3.10+, curl과 네트워크 연결이 필요합니다. 서버는 시작 시 오래된 수집본을 갱신하고, 이후 매일 한국 시간(Asia/Seoul) 자정에 새 헤드라인을 수집합니다. 최근 하루와 현재 날짜의 실제 발행 기사에서 언론사별 최대 5개, 국가별 최대 20개 제목을 선별합니다. 수집에 실패하면 기존 수집본을 보존하고 5분 이내 재시도합니다. 일부 국가 실패는 화면에 표시합니다.

열린 브라우저는 자정에 날짜를 바꾸고 데이터를 다시 요청합니다. 수집 완료를 확인하도록 5분마다, 탭 복귀 시에도 재요청합니다. 날짜와 기사 발행일은 한국 시간으로 표시합니다. 자정에 수집을 시작하므로 새 목록 반영에는 수집 시간이 걸립니다.

**자동 기사 수집에는 이 서버가 계속 실행되는 호스팅이 필요합니다.** 기존 `.openai/hosting.json`은 `dist` 정적 배포 설정입니다. 정적 배포만으로는 Python 수집기를 실행할 수 없습니다. 파일을 직접 열거나 정적 호스팅을 쓰면 보관된 제목을 표시하고 자동 수집 서버 연결 불가 상태를 안내합니다. 서버 운영 환경으로 배포하거나 별도 일일 수집·배포 작업을 연결해야 운영 사이트에도 자동 갱신이 적용됩니다.

수동 수집: `python3 scripts/collect.py` 또는 `python3 scripts/collect.py YYYY-MM-DD`. 수집기는 제목과 메타데이터만 수집합니다. Google News RSS 기반으로 전체 세계 기사를 망라하지 않으며 국가 분류는 언론사·뉴스판 기준입니다.
