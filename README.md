# World In Words

24개 국가·지역의 당일 헤드라인을 모으는 텍스트 전용 신문. 날짜는 한국 시간 기준이며 전날 기사는 자정부터 제외합니다. 제목과 본문 한국어 번역·원어 전환을 제공합니다. 기본 정렬은 사이트에서 집계한 원문 링크 조회순입니다. 같은 이용자는 기사별 한국 시간 하루 한 번 집계하며 언론사의 외부 조회수와는 별개입니다. 최신순·오래된순은 제공하지 않습니다.

## 운영 사이트의 갱신

운영 사이트는 Sites Worker에서 Google News RSS를 직접 수집하고 전체 당일 수집본을 R2 BUCKET의 headlines/latest.json에 보관합니다. 컴퓨터나 PyCharm이 꺼져 있어도 사이트가 동작합니다. 기존 본인 계정 전용 접근 범위를 유지합니다.

GET /api/headlines는 저장된 당일 기사만 반환합니다. 수집본이 없으면 즉시 수집하고, 15분 이상 지난 수집본은 화면을 유지하면서 다시 수집합니다. 전날 기사는 반환하지 않습니다. 일부 국가가 실패하면 그 국가의 당일 수집본만 유지합니다. 전체 RSS 실패는 기존 수집본을 덮어쓰지 않고 503으로 보고합니다. 정상적인 빈 피드와 연결 실패를 구분합니다.

POST /api/refresh는 새 수집본을 저장하는 공유 갱신 경로입니다. 배포 서버의 직접 RSS 연결이 제한되면 GET /api/sources에서 공개 RSS 주소를 얻어 예약 작업이 직접 수집하고 POST /api/snapshot으로 저장합니다. 업로드는 당일 실제 발행 기사만 검증해서 저장합니다. 현재 owner-private Sites의 플랫폼 접근 경계로 보호됩니다. 사이트를 공개로 변경하려면 이 쓰기 경로에 별도 인증을 먼저 추가해야 합니다.

업로드 본문은 UTF-8 JSON 바이트로 직접 전송합니다. JSON을 curl 설정 파일의 `data =` 문자열 안에 넣으면 유니코드 이스케이프가 손상될 수 있습니다. `python3 scripts/upload_snapshot.py <현재 Sites URL>`은 안전하게 전송한 뒤 저장된 제목·언론사가 원본과 일치하는지 확인합니다. 서버는 연속된 `uXXXX` 또는 중복 이스케이프 형태의 손상된 제목·언론사를 발견하면 전체 업로드를 거부하고 기존 수집본을 보존합니다.

## 클라우드 예약 작업

매 실행은 Sites get_site로 동일 Site를 다시 열고, 현재 live URL과 플랫폼 서비스 접근 자격을 얻습니다. 자격은 메모리에서만 보관하며 해당 Site의 OAI-Sites-Authorization 헤더에만 사용합니다. POST /api/refresh를 호출합니다. 실패하면 GET /api/sources의 RSS를 직접 읽어 한국 시간 당일의 제목·언론사·실제 발행일만 추출하고 국가별 최대 50개를 POST /api/snapshot으로 업로드합니다. GET /api/headlines를 읽어 collectedAt, end, 실제 발행일, 오류 수를 확인합니다. RSS는 공개 소스이며 연결 앱이나 방문자 동의가 필요하지 않습니다. 전체 실패 시 잠시 후 한 번만 재시도하고 실패 상태를 보고합니다. 소스 수정·재배포는 일상 갱신에 필요하지 않습니다. 토큰을 소스·로그·예약 문구에 넣지 않습니다.

## 로컬 실행

python3 scripts/serve.py 8765

http://localhost:8765 에서 열 수 있습니다. 이 주소는 서버가 실행 중일 때만 작동하며 컴퓨터가 꺼지거나 프로세스가 종료되면 연결이 거부됩니다. PyCharm의 HTML 미리보기나 파일 직접 열기는 수집 서버를 실행하지 않습니다.

Python 3.10+, curl과 네트워크 연결이 필요합니다. 시작 시 오래된 데이터를 수집하고 자정과 당일 15분 간격으로 갱신합니다. 수동 수집은 python3 scripts/collect.py이며 news.js와 dist/news.js를 동시에 갱신합니다.

## 배포 빌드

python3 scripts/build.py

기존 화면과 RSS 수집 설정을 dist/server/index.js의 Cloudflare 호환 Worker로 묶습니다. .openai/hosting.json의 project_id는 그대로 유지합니다. 자료는 국가별 최대 50개이며 실제 확보된 기사만 표시합니다. 국가 분류는 언론사·뉴스판 기준입니다.

한국 코너는 제목에 한글이 포함된 한국어 원문 기사를 수집합니다. 같은 국내 언론사 도메인의 영문판 제목은 수집·예약 업로드·저장본 조회에서 제외하며 자동 번역으로 대체하지 않습니다. BTS·AI 등 영문 고유명사가 섞인 한국어 제목은 유지합니다.

## 기사 펼쳐보기

GET /api/article?id=…는 저장된 당일 기사만 읽습니다. 출판사 직접 주소 또는 Google News 원문 주소를 확인하고 공개된 NewsArticle articleBody나 article/main의 문단을 텍스트로 추출합니다. 본문에 스크립트·이미지를 표시하지 않으며 언론사 출처 링크를 남깁니다. 제목·본문 번역은 Google 번역에 번역할 텍스트를 전송하고 연결·요청 제한 시 MyMemory 번역을 사용합니다. 번역 서비스의 일일 한도를 초과하면 본문을 유지하고 재시도를 제공합니다. 유료·로그인 제한을 우회하지 않고 사이트가 접근을 거부하거나 구조를 해석할 수 없으면 원문 링크를 안내합니다. 원문 텍스트는 개인용 R2에 캐시하며 사이트 접근 범위를 그대로 유지합니다.

RSS 수집과 /api/snapshot 업로드는 url, publisherUrl, sourceUrl을 보존합니다. 예약 작업에서 원문 링크를 포함해야 신규 기사의 펼쳐보기 주소도 보존됩니다. 이전 수집본과 동일 ID는 주소 메타데이터를 이어받습니다.


## 계정과 Supabase 보관함

Supabase 프로젝트 `nignumzfwicpjgnjmhgb`(서울)에 계정, 해시 비밀번호, 해시 세션, 기사 메타데이터, 조회 집계, 연도별 개인 열람 기록, 스크랩을 저장합니다. 데이터 정의는 `supabase/migrations/`에 있습니다. 스크랩과 열람 기록은 해당 계정만 조회할 수 있습니다. 연도는 한국 시간의 **열람 연도**이며 자동 삭제하지 않습니다. 스크랩은 저장 연도로 필터링합니다. 원문 링크를 여는 `/go/:id`에서 기록을 저장한 후 출처로 이동합니다. 본문 펼쳐보기는 조회수에 포함하지 않습니다. 적용 전 방문은 복구할 수 없습니다.

아이디는 영문·숫자·밑줄 3–24자, 비밀번호는 8자 이상·UTF-8 64바이트 이내입니다. 이메일·전화번호를 수집하지 않아 계정 복구 수단도 없습니다. 비밀번호는 pgcrypto bcrypt(cost 12)로 해시하며 원문 저장·출력하지 않습니다. 세션은 임의 256비트 토큰을 Secure·HttpOnly·SameSite=Lax 쿠키에 보관하고 DB에는 SHA-256 해시만 저장합니다. 만료는 30일이며 로그아웃은 서버 세션을 폐기합니다. 로그인 실패는 아이디별 15분에 8회로 제한합니다.

Sites의 기존 비공개 접근 범위 위에 앱의 아이디 로그인이 추가됩니다. 공개 범위는 바꾸지 않습니다. 개인정보 보관함은 Sites 서비스 접근만으로 열리지 않으며 앱 세션이 필요합니다. Supabase의 비공개 `wiw` 스키마 테이블은 RLS로 기본 거부합니다. `wiw_api` 함수는 backend service_role만 실행할 수 있습니다. Edge Function은 Sites 서버의 ECDSA P-256 서명을 확인한 요청만 받아 DB 함수를 호출합니다. 공개 검증 키만 소스에 있으며 개인 키는 Sites 런타임 비밀값에만 저장합니다.

런타임 설정 이름: `SUPABASE_RPC_URL`, `WIW_RPC_SIGNING_KEY`(secret). `supabase/functions/wiw-reader/index.ts`는 공개 검증 키가 들어있는 서명 검증 중계 코드입니다. 키를 교체할 때는 Edge Function의 공개 키와 Sites의 비밀 개인 키를 함께 교체합니다. 키 값은 저장소나 출력에 남기지 않습니다.

로컬 Worker 미리보기: Node 실행 경로로 `scripts/dev.mjs 8765`를 실행하고, 숨김 stdin에 두 환경값의 JSON을 전달합니다. 임시 검증용이며 실제 인증값을 파일에 저장하지 않습니다. 테스트: `node --test tests/*.test.mjs`.
